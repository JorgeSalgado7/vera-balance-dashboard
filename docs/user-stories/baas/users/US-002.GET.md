# US-BAAS-USERS-002 — Obtener todos los usuarios

**Aplicación:** BAAS  
**Módulo:** Users  
**Endpoint:** `GET /users`  
**Status:** `under review`

## Historia de usuario

Como administrador, quiero obtener todos los usuarios registrados en el sistema para consultar y gestionar los administradores, responsables de clínica y terapeutas, independientemente de la clínica a la que pertenezcan.

## Reglas de negocio

1. Únicamente los usuarios con rol `admin` podrán consultar el listado global de usuarios.
2. Los usuarios con rol `clinic` o `therapist` no podrán acceder a este endpoint.
3. La consulta deberá recuperar todos los usuarios registrados en el sistema, independientemente de su clínica.
4. Se deberán incluir usuarios con estado `Activo` e `Inactivo`.
5. La consulta deberá realizarse mediante `Query` utilizando `GSI1`, de acuerdo con la definición de DynamoDB.
6. La búsqueda utilizará `gsi1pk = 'USER'` para recuperar exclusivamente registros de usuarios.
7. No se permitirá utilizar operaciones `Scan`.
8. La respuesta deberá respetar estrictamente el esquema `User` definido en OpenAPI.
9. No se deberá exponer el campo `password`, su hash ni los atributos internos de DynamoDB.
10. Si no existen usuarios registrados, se deberá devolver una colección vacía.
11. La implementación deberá respetar los modelos, campos y contratos definidos en OpenAPI y DynamoDB.
12. No se deberán agregar campos, relaciones, filtros ni comportamientos que no estén contemplados en los documentos del proyecto.

## Criterios de aceptación

- **CA01:** Un usuario con rol `admin` puede obtener todos los usuarios registrados en el sistema.
- **CA02:** Un usuario con rol `clinic` o `therapist` recibe una respuesta `403 Forbidden` al intentar acceder al endpoint.
- **CA03:** El listado incluye usuarios de todas las clínicas, así como usuarios sin clínica asociada.
- **CA04:** La respuesta incluye usuarios con estado `Activo` e `Inactivo`.
- **CA05:** La consulta utiliza `GSI1` mediante `Query`, sin realizar operaciones `Scan`.
- **CA06:** La respuesta cumple con el esquema `User` de OpenAPI y no expone contraseñas ni atributos internos de persistencia.
- **CA07:** Cuando no existen usuarios registrados, el endpoint responde `200 OK` con un arreglo vacío.
- **CA08:** Si DynamoDB devuelve resultados paginados, se recuperan todas las páginas necesarias para completar el listado.
